## 📂 Proyectos destacados

### 🏪 SurtiEsquina — Sistema de Información y Gestión Comercial

<img src="https://img.shields.io/badge/Proyecto-Académico-16A34A?style=flat-square" alt="Proyecto académico"/> <img src="https://img.shields.io/badge/Database-MySQL-4479A1?style=flat-square&logo=mysql&logoColor=white" alt="MySQL"/> <img src="https://img.shields.io/badge/Análisis-Sistemas-2563EB?style=flat-square" alt="Análisis de sistemas"/>

Sistema propuesto para mejorar la gestión de una tienda de barrio mediante el control de inventario, ventas, recepción de mercancía, proveedores y caja.

**Principales funcionalidades y aportes:**
- Diseño de una base de datos relacional con entidades para usuarios, categorías, productos, compras, recepciones, inventario, cajas y ventas.
- Consultas y vistas para inventario actual, productos con bajo stock, productos vencidos y ventas detalladas.
- Definición de requerimientos funcionales, reglas de negocio e historias de usuario.
- Diseño de interfaces para los roles de administrador y cajero.

**Tecnologías:** MySQL · SQL · MySQL Workbench · PlantUML · Lucidchart · v0.app.

🔗 **Enlaces:** [Repositorio](URL_DE_TU_REPOSITORIO) · [Prototipo](URL_DE_TU_PROTOTIPO) · [Documentación](URL_DE_TU_DOCUMENTACION)

### 🧩 Análisis y modelado de sistemas

Diseño de artefactos técnicos para representar procesos de negocio, requerimientos y estructuras de datos antes de implementar una solución.

- Diagramas de casos de uso y procesos.
- Modelos conceptuales, lógicos y relacionales.
- Historias de usuario y reglas de negocio.
- Documentación de requerimientos funcionales y no funcionales.

**Herramientas:** PlantUML · Lucidchart · MySQL Workbench.

### 📊 Investigación y análisis de información

Proyecto académico orientado al estudio de la oferta y demanda de servicios domiciliarios en San Gil, con recopilación de información mediante formularios digitales y preparación de datos para su análisis.
