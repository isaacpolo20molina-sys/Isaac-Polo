## 🚀 Sobre mí

Soy estudiante de **Análisis y Desarrollo de Software en el SENA**, interesado en el diseño, análisis y desarrollo de soluciones tecnológicas para resolver problemas reales.

Mi enfoque actual está en el diseño de bases de datos relacionales, el análisis de requerimientos, el modelado de sistemas de información, la documentación técnica y el prototipado de interfaces web.

Me interesa comprender las necesidades de un negocio, estructurar una solución y convertir sus requerimientos en funcionalidades claras y organizadas.

- 🗄️ Diseño y estructuración de bases de datos.
- 🧩 Análisis de requerimientos y modelado de sistemas.
- 🌐 Diseño y prototipado de interfaces web.
- 📊 Organización y análisis de información.
- 📐 Documentación técnica y diagramación.
- 📚 Aprendizaje continuo y desarrollo de habilidades tecnológicas.

## 📂 Proyectos destacados

### 🏪 SurtiEsquina — Sistema de Información y Gestión Comercial

<p>
  <img src="https://img.shields.io/badge/Proyecto-Académico-16A34A?style=flat-square" alt="Proyecto académico"/>
  <img src="https://img.shields.io/badge/Base%20de%20datos-MySQL-4479A1?style=flat-square&logo=mysql&logoColor=white" alt="MySQL"/>
  <img src="https://img.shields.io/badge/Área-Análisis%20de%20sistemas-2563EB?style=flat-square" alt="Análisis de sistemas"/>
</p>

Sistema de información diseñado para mejorar la gestión de una tienda de barrio de Medellín mediante el control de inventario, ventas, recepción de mercancía, proveedores y caja.

**Principales funcionalidades y aportes:**

- Diseño de una base de datos relacional con entidades para usuarios, categorías, productos, compras, recepciones, movimientos de inventario, cajas y ventas.
- Elaboración de vistas SQL para consultar inventario actual, productos con existencias bajas, productos vencidos, ventas detalladas, proveedores y ganancias por producto.
- Definición de requerimientos funcionales, reglas de negocio e historias de usuario.
- Diseño de interfaces para los roles de administrador y cajero.

**Tecnologías:** MySQL · SQL · MySQL Workbench · PlantUML · Lucidchart · v0.app.
